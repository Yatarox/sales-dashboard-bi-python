# Retail Sales Analysis - Data Science Project

## Objectif
Analyse des ventes d'une chaîne de magasins.

## Pipeline
1. DataLoader → Chargement
2. DataCleaner → Nettoyage
3. FeatureEngineering → Features
4. EDA → Analyse

## Résultats
- 24 784 clients uniques
- 120 produits
- 32 features créées
- Insights business identifiés

## Technologies
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
